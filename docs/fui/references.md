# 参考文献

FUI の原則を組み立てるときに参照した資料。各項目に、何が書かれているかと、
どの原則（[principles.md](principles.md) の P1〜P7）の根拠になっているかを付ける。
新しい資料を読んだらここに追記し、原則やパターンから参照する。

## 実務者のインタビュー

### Mark Coleran（FUI という語を広めたデザイナー）

- [Pragmatic futurism and screen graphics – interview with Mark Coleran](https://www.pushing-pixels.org/?p=18414)（Pushing Pixels）
  - 現実の UI を土台に誇張する「実用的な未来主義」。→ P4
- [Mark Coleran interview（Gizmodo, Pushing Pixels アーカイブ）](https://pushing-pixels.org/coleran/interviews/gizmodo/index.html)
  - 映画の UI は「インターフェースではなくプロットの可視化」。機械の強さや悪役の手強さを暗示することが目的。→ P1, P5
- [Faking good design in film – Wireframe podcast episode 12](https://xd.adobe.com/ideas/perspectives/wireframe-podcast/faking-good-design-in-film-episode-12)（Adobe）
  - 映画の UI はアニメーションで現実の UI より先を行っていた。Windows を下敷きにして見慣れた印象を作った例。Robyn Haddow の「24 フレームで理解できること」。→ P2, P3, P4

### Territory Studio

- [The craft of screen graphics and movie user interfaces – interview with David Sheldon-Hicks](https://www.pushing-pixels.org/?p=9769)（Pushing Pixels）
  - 監督・美術・VFX と制作の各段階で協働し、作品ごとのルックに合わせるプロセス。→ P7
- [The art and craft of screen graphics – interview with Peter Eszenyi](https://www.pushing-pixels.org/?p=13856)（Pushing Pixels）
  - どれだけ美しくても物語を語り、監督のビジョンを支えること。画面を凝視させる時間はない。→ P2, P7

### Jayse Hansen（Iron Man / The Avengers の HUD）

- [The craft of screen graphics and movie user interfaces – conversation with Jayse Hansen](https://www.pushing-pixels.org/?p=7447)（Pushing Pixels）
  - ステレオ 3D 撮影がヘルメット HUD の設計に与えた影響。技術文献を調べて「もっともらしい」視覚言語を作る。→ P4, P5
- [Design of "The Avengers" – interface designs and HUDs](https://www.hudsandguis.com/2013/05/15/the-avengers/)（HUDS+GUIS）
  - 3D ではすべてが鮮明に見えるため、要素すべてに機能を持たせた。要素が異なる奥行きの層でアニメーションする。→ P5, チェックリスト C12

## 調査・研究

- [Future Screens Are Mostly Blue](https://99percentinvisible.org/episode/future-screens-are-mostly-blue/)（99% Invisible）
  - 『Make It So』の調査で、SF 映画の画面は青が支配的。青は自然界に少なく人工的に見える。→ P6
- [Not So Strange, These Fictions](https://oldmagazine.uxpa.org/not-so-strange-these-fictions)（UXPA Magazine）
  - 『Make It So』の書評。SF の GUI ではサンセリフ体がセリフ体を圧倒的に上回る。→ P6
- Nathan Shedroff, Chris Noessel『Make It So: Interaction Design Lessons from Science Fiction』（Rosenfeld Media, 2012）
  - SF 映画の UI を体系的に調査し、現実の設計への教訓を引き出した書籍。上の 2 つの元。
