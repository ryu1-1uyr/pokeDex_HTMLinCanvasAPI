# FUI ナレッジベース

この図鑑を題材に、FUI（Fictional / Fantasy User Interface）の「それっぽさ」を言語化し、
次の作品でも再現できるように残していく場所。

| ファイル | 内容 |
| --- | --- |
| [principles.md](principles.md) | 原則。なぜそう作るのか。出典つき |
| [grammar.md](grammar.md) | 文法。色・線・書体・余白・モーション・レイヤーのルールとトークン |
| [patterns.md](patterns.md) | パターン集。レシピと実装場所、未実装の候補 |
| [checklist.md](checklist.md) | レビュー用チェックリストと採点履歴 |

## 進め方

1. **作る**: 1 つの演出を実装する。
2. **言語化する**: なぜそれっぽく見えるのかを、原則（P1〜）に紐づけて説明する。
3. **ルールにする**: 数値はトークンに、作り方はパターンに追記する。
4. **採点する**: チェックリストで採点し、点の低い観点から次の改善を選ぶ。

ドキュメントとコードが食い違ったら、どちらかを直す。トークンの値を変えるときは
`src/ui/fui-tokens.css` とシェーダーの定数を同時に変える。
